# Ride Analytics Dashboard

An interactive Ride Analytics Dashboard built using HTML, CSS, and JavaScript.

## Features
- CSV File Upload
- Total Rides
- Total Revenue
- Average Rating
- City-wise Filter
- Driver Search
- Revenue Chart
- Ride Status Pie Chart
- Top Drivers Table
- Dark Mode
- Download CSV Report
- Download Dashboard PDF

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Chart.js
- PapaParse
- jsPDF

## How to Run
1. Download the project.
2. Open index.html in your browser.
3. Upload a CSV file.
4. Explore the dashboard.
